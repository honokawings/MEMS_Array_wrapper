# 麦克风阵列前处理算法冻结规格 v1.0

算法冻结日期：2026-09-15。依据根目录 README、用户确认的 64 根共享 DATA 接线和“优先声源定位，带宽可缩小”的要求。定点格式、系数和抽取相位保持冻结；2026-09-16 根据 PG2L200H 的真实路径预算，将有效数据窗口内的引脚采样点后移一拍。器件和传输实现另见完整系统文档。

## 目标与数据链

128 路 IM72D128V01，共用一个 3.072 MHz PDM 时钟。输入系统时钟 **122.88 MHz**，整数 40 分频，50% 占空比；由板级时钟源或 PLL 提供这一系统时钟。冻结版本不支持直接接任意频率的系统时钟，也不使用会引入周期抖动的分数分频。

```text
64 × 共享 PDM DATA
  → 双相采集、统一 PDM 周期编号
  → CIC5 /8：384 kHz，Q2.30
  → CIC 补偿 FIR63 /4：96 kHz，Q2.30
  → 抗混叠 FIR127 /2：48 kHz，Q2.30
  → 逐通道静态偏置与增益校准
  → Q1.23 PCM + 通道号 + 64 位帧号 + first/last
```

保证通带 **20 Hz～16 kHz**，通带峰峰纹波 <0.01 dB；折入此通带的镜像抑制目标 >120 dB。16～24 kHz 属于过渡带或阻带，不供定位算法作为保证有效带宽使用。DC 默认保留；静态偏置校准可减去 DC，不加入独立 AGC、门限降噪或通道相关的自适应滤波。

## 输入、相位与启动

- `pdm_data[k]`：偶数通道 `2*k` 为 LR=GND，在下降沿后驱动；奇数通道 `2*k+1` 为 LR=VDD，在上升沿后驱动。
- 每个周期先收集高半周期的奇数通道，再收集低半周期的偶数通道，组成一个完整的 128 位 PDM 向量。该顺序与上位机输出通道升序独立。
- 两级输入寄存器连续采样。逻辑选取半周期开始后的第 19 个系统时钟，实际对应第 17 个系统时钟处进入第一级寄存器的数据，即约 **138.346 ns** 的原始引脚采样时刻。仍选取同一个 PDM 位，不改变通道配对、抽取相位或帧号。
- 本地手册的 tDV 最大 100 ns，留给输出时钟延迟、往返布线、输入延迟及不确定性的建立余量约 **38.346 ns**；距下一个半周期边沿仍有 3 个系统周期（24.414 ns）。集成时必须根据具体 FPGA、时钟树和 PCB 重新计算，不能把两级寄存器当成所有输入时序的保证。
- 默认先运行麦克风时钟并丢弃 153600 个 PDM 周期，约 50 ms；随后所有数字状态从零开始接收。额外丢弃前 96 个 PCM 帧，覆盖滤波器启动响应。
- `enable=0` 在下一个系统时钟清空采集与处理状态、FIFO、帧号及状态标志，并拉低麦克风时钟。校准配置在 disable 时保留，`rst_n=0` 时恢复单位增益与零偏置。
- 停止允许截断正在输出的 PDM 半周期；它是立即关闭行为。重新启动必定重新等待 50 ms。上游须同步 enable/rst_n。

数字滤波不会给不同通道引入不同延迟。**LR 的数据输出半周期差不等于已经证实的声学采样偏差**：本实现按共同 PDM 周期配对，不擅自对其中一组插入半周期延迟。器件内部时延、LR 相关偏置、麦克风位置和声学安装误差需通过实测标定。实际阵元坐标未提供，工程不虚构螺旋几何。

## 数学及定点契约

用 `bit=1 → +1`、`bit=0 → −1` 映射。全部状态在运行开始时为零。

1. CIC：5 级积分器均采用上一 PDM 周期的前级状态：`I0'=I0+x`，`Ik'=Ik+I(k-1)`。第 8、16……个输入周期抽取 `I4'`，经过 5 级差分。积分器及梳状状态均为 32 位模 2³² 运算，**不能饱和**。这种结构等价于五个长度 8 的滑动和，再加 4 个 PDM 周期公共延迟。总 DC 增益为 8⁵=32768；有界输出乘 2¹⁵ 后成为 Q2.30，CIC 中不丢弃有效位。
2. FIR1：63 taps，输入 384 kHz，每第 4 个输入样本计算一次。浮点设计用分段线性逆 CIC 目标进行最小二乘设计，通带 0～16 kHz，阻带从 80 kHz 开始。
3. FIR2：127 taps，输入 96 kHz，每第 2 个输入样本计算一次。等波纹低通，通带 0～16 kHz，阻带从 24 kHz 开始。
4. 两组系数为 **32 位有符号、30 位小数**，记作 Q2.30（整数部分包含符号位）。系数严格对称，中心系数修正确保整数和恰好为 2³⁰。以 `lib/coeff/*_q30.txt` 为冻结整数系数，`.hex`、`.svh` 与 `.npy` 由同一生成器输出。
5. FIR 32×32 位有符号乘法，64 位乘积，72 位 RTL 累加器。结束后除以 2³⁰，采用**最近舍入，半值远离零**，再饱和到 32 位。C++ 使用 64 位累加器：系数 L1 范数分别约 1.515、1.981，所有合法 32 位输入的绝对乘积和都小于 2⁶³；生成器和 Cmodel 检查此界限。
6. 校准：`pcm = sat24(round_away((fir2_q30 − offset_q30) × gain_q22 / 2²⁹))`。偏置 32 位 Q2.30；增益 24 位、22 位小数，范围 [−2,2)，缺省 +1，可用负增益做极性修正。差值保留 33 位，乘积 57 位，舍入扩展至 58 位。最终 24 位二补码为 Q1.23。
7. FIR 与校准饱和置位 `clipped`，直到 disable/reset。该标志是采集期间的粘滞汇总，并非逐样本标签。极端输入和校准增益可能产生饱和，不能对饱和样本声称相位/幅度保真。

## 精度与时间轴

麦克风在 94 dBSPL 下灵敏度约 −36 dBFS，SNR 72 dB(A)，对应噪声约 −108 dBFS(A)。附加噪声控制目标为使理论 SNR 损失小于 0.1 dB；不能从“24 位输出”直接推断达成。

滤波器公共群延迟为 `4 + 5×(8−1)/2 + 31×8 + 63×32 = 2285.5` 个 PDM 周期，即 743.977865 μs。脉冲响应包括前导零共 4568 个 PDM 周期，小于 96×64。

定义启动等待结束后的首个有效 PDM 周期为 n=0。`pcm_frame_id=m` 对应滤波前时间索引 **n=64m+63**，滤波后对应输入中心为 `64m+63−2285.5`。前 96 帧被抑制，因此缺省首个输出帧号为 96。FIFO 等待及通道串行输出时间不改变这个采样时间标签。
